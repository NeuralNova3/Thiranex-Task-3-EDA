 Exploratory Data Analysis (EDA) of Roller Coasters
Project Overview
This project performs Exploratory Data Analysis (EDA) on a roller coaster dataset to identify patterns, trends, distributions, and relationships among different roller coaster characteristics.
This project was completed as part of Thiranex Internship – Task 3.
Objectives
•	Understand the structure of the dataset.
•	Identify and handle duplicate records.
•	Examine missing values.
•	Perform statistical analysis.
•	Create meaningful data visualizations.
•	Explore relationships between numerical variables.
•	Identify useful insights from the dataset.
Dataset Description
•	Total records: 1,087 roller coasters.
•	Data includes names, speed, height, location, status, manufacturer, opening year, and other characteristics.
•	Dataset format: CSV.
Dataset Source:
https://gist.githubusercontent.com/Panchajanya1999/4310286fdb4e22f21c0726975f58b36e/raw/8f04fb5ef4ecc6ea37483b4aa73006a76a2d3449/coaster_db.csv
Technologies and Libraries Used
•	Python
•	Google Colab
•	Pandas
•	NumPy
•	Matplotlib
•	Seaborn
Project Workflow
1. Data Loading
Loaded the roller coaster dataset using Pandas.
2. Data Inspection
Examined dataset dimensions, column names, data types, missing values, duplicate records, and statistical summaries.
3. Data Cleaning
•	Standardized column names.
•	Removed duplicate records.
•	Removed completely empty columns.
•	Preserved partially missing records for further analysis.
4. Statistical Analysis
Calculated descriptive statistics, including mean, maximum, minimum, and standard deviation.
5. Data Visualization
Created visualizations to examine:
•	Roller coaster types.
•	Operating and other status categories.
•	Distribution of opening years.
•	Top roller coaster manufacturers.
6. Correlation Analysis
Created a correlation matrix and heatmap to explore relationships between numerical variables.
Key Findings
1.	The dataset contains 1,087 roller coaster records.
2.	Steel is the most common roller coaster type, with 308 records.
3.	668 roller coasters are listed as operating.
4.	Vekoma is the most frequently listed manufacturer, with 135 records.
5.	Bolliger & Mabillard has 119 records.
6.	Intamin has 99 records.
7.	The average recorded speed is approximately 48.62 mph.
8.	The average introduction year is approximately 1995.
9.	The dataset contains 29,435 missing cells, indicating that some characteristics are not available for every roller coaster.
Conclusion
This project demonstrates how Exploratory Data Analysis can be used to understand real-world datasets and discover meaningful patterns.
Through data inspection, cleaning, statistical analysis, visualization, and correlation analysis, useful insights about roller coaster characteristics were identified.
The project helped develop practical skills in Python, data manipulation, data visualization, and analytical thinking.
